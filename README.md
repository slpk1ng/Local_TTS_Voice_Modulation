# 本地TTS语气变化 v1.1.6

- 基于 AstrBot 的全自动情绪 TTS 插件。支持通过本地大模型自动判断语境情绪，联动本地 GPT-SoVITS 生成带情绪起伏的自选语种语音，并实现**自选语种文本 + 自选语种语音双回复**，直接发送至 QQ。

- 为什么做这个插件？插件市场里面不是已经有了类似的吗：因为对于新手来说（我真不会用），使用这些插件是有点困难的，于是我用DeepSeek结合丛雨AIpet中的相似JSON做了对新入坑astrbot的人更加友好的插件。（没有说别的插件做得不好的意思）

- 本插件目前仅支持本地部署的模型，无法使用云API key。

- 对于没有 NVIDIA CUDA 的人群：请修改插件中“TTS 合成设备”为 cpu。

## ✨ 功能特性

- **全自动情绪路由**：根据大模型判断的语境，自动在 平静、高兴、害羞、生气、惊讶、着急 等情绪之间切换语气。

- **双回复模式**：大模型同时生成中文台词和自选台词，QQ 中先发送自选语音，紧接着发送自选文本。

- **外部目录自动扫描**：插件强制要求在插件UI中配置外部参考音频根目录，自动扫描根目录下的子文件夹作为情绪库。

- **参考文本自动加载**：自动读取对应文件夹下的 `asr.txt` 作为 TTS 参考文本，无需手动粘贴。

- **严格 JSON 输出**：内置细致的人格提示词，强制大模型输出例如 `{"zh": "中文台词", "ja": "日语台词", "emotion": "情绪"}` 格式，防止模型乱回。

- **GPT-SoVITS 全参数可调**：整合了详细推理参数（Top-K、Temperature、切分方法、批处理等），用户可在插件UI中自由调节语音质量、随机性和语速。

- **深度思考（Think）**：开启后模型会先进行内部推理，大幅度提升对复杂指令和长对话的理解能力，解决小模型“失忆”和“敷衍”的问题。

- **按角色管理记忆**：记忆文件按“角色标识符”独立保存在全局目录中，卸载或重装插件也不会丢失记忆，且支持在UI中扫描、删除指定角色的记忆文件。

- **语音缓存自动清理**：自动限制临时音频文件的数量，防止长时间使用后磁盘被占满。

## 📦 环境要求

- 已部署并运行的 **AstrBot** 实例（v4.x 版本）。

- 本地 **Ollama** 或 **OpenAI 兼容服务**（配置好对话模型，如 `qwen3:8b`）。

- 本地 **GPT-SoVITS** 服务（运行于 `http://127.0.0.1:9880`）。

- **重要**：参考音频必须存放在 **外部可访问的常规目录**（如 `C:/tts/yuqi/`），严禁放入 `%APPDATA%` 等隐藏系统目录。


## 🧠 配置本地大语言模型（LLM）后端

本插件支持 **Ollama** 以及所有 **OpenAI 兼容接口** 的本地部署软件（如 LM Studio、vLLM、LocalAI 等）。请在插件配置面板中，根据你使用的软件填写以下三项：

### 📋 配置参数对照表

| 软件 | 【LLM后端类型】 | 【LLM服务地址】 | 【大语言模型名称】 | 【本地模型API Key】 |
| :--- | :--- | :--- | :--- | :--- |
| **Ollama** | `ollama` | `http://127.0.0.1:11434` | `自定义` | 留空 |
| **LM Studio** | `openai` | `http://127.0.0.1:1234/v1` | `自定义` | 任意字符串（如 `lm-studio`） |
| **vLLM** | `openai` | `http://127.0.0.1:8000/v1` | `自定义` | `EMPTY` |
| **LocalAI** | `openai` | `http://127.0.0.1:8080/v1` | `你的 gguf 模型名` | `EMPTY` |

### 🛠️ 配置步骤

1. 在插件 插件 UI 面板中找到 **【LLM后端类型】**。

2. 根据你使用的软件，选择 `ollama` 或 `openai`。

3. 填写 **【LLM服务地址】**（注意：OpenAI 兼容接口通常需要在末尾加 `/v1`）。

4. 填写 **【大语言模型名称】**（必须与你本地部署的模型名称完全一致）。

5. 填写 **【本地模型API Key】**（Ollama 留空，OpenAI 兼容接口一般填任意字符串或 `EMPTY`）。


## ⚠️ 注意事项

- 如果你使用的是 **OpenAI 兼容后端**，但模型返回的内容不是严格的 JSON 格式（例如纯文本），请检查【JSON提示词】是否足够强硬。

- 对于 **LM Studio**，请确保已在软件中启动本地 API 服务，并允许跨域访问。

- 修改配置后，请务必在 插件 UI 中点击 **保存并重载插件** 使新配置生效。


## 🎁 如何自定义新语气？（适配大众）

1. 在上述根目录下新建一个拼音文件夹（例如你想加“傲娇”，就建一个名为 `aojiao` 的文件夹）。

2. 将音频文件命名为 `ref.mp3`（或 `ref.wav`）放入该文件夹。

3. 在 插件 UI 中新增情绪映射配置并填写所需。

4. 重载插件。代码会自动扫描出 `aojiao`，并将其加入大模型的情绪列表中。


## 🚀 速度优化建议

- **精简提示词**：如果觉得仍慢，可以手动精简提示词，去除冗余描述。

- **开启深度思考**：如果需要模型准确理解复杂的上下文指令，或AI太傻没不懂潜在意思，建议开启【深度思考】，但会牺牲一定响应速度。

- **删去人格提示词中的第二段JSON**：让AI一次只回复一种语气。**通常不建议**，因为会导致在同一句话中语气应有明显不同时，只会有第一种语气。


## ❓ 常见问题

- **没有声音/合成失败 (400 Bad Request)**：请检查“参考音频根目录”是否填写了外部常规目录（如 `C:/tts/yuqi/`），严禁填写 `C:/Users/AppData/.astrbot/...` 这种隐藏系统目录。

- **语气没有变化**：请确保开启了 `llm_judge`，并且 `ref.mp3` 本身情绪饱满（不要用太平的音）。

- **模型不听话（不输出 JSON）**：请检查 **人格提示词** 中是否包含了强制输出 `{"zh": "...", "ja": "...", "emotion": "..."}` 格式的约束语句（插件已内置）。

- **后台日志显示乱码**：插件已内置强制 UTF-8 输出修复。若依然显示乱码，请务必检查文件夹是否使用了中文命名，统一改为拼音即可。

- **怎么运行本地 GPT-SoVITS 服务**：在文档上方有GPT-SoVITS 服务的链接，请没有下载的人群前往下载。丛雨模型请查看此md文档最上方有github链接供安装。


## ⚙️ 配置说明（插件UI 中必须填写）

### 核心路由配置

| 配置项 | 说明 |
| :--- | :--- |
| **是否使用 LLM 自动判别情绪** | 开启后，大模型会根据语境自动选择情绪。关闭则固定使用默认情绪。 |
| **GPT-SoVITS 服务地址** | 填写本地 API 地址，默认为 `http://127.0.0.1:9880`。 |
| **参考音频根目录** | **【必填】** 填写外部绝对路径，例如：`C:/tts/yuqi/`。 |
| **默认情绪** | 当大模型无法识别情绪时使用的兜底情绪（必须与文件夹名一致，默认 `pingjing`）。 |
| **人格提示词 / JSON提示词 / 补充提示词** | 内置了完整的丛雨人格设定及 JSON 输出要求，可自行修改。 |
| **情绪映射配置** | **【可选】** 留空（保持暂无条目）即可自动扫描外部目录。 |
| **角色名称 / 角色标识符** | 用于显示在对话中及本地记忆文件的命名。角色标识符必须为纯英文/拼音。 |
| **开启深度思考** | 开启后模型会先进行内部推理，大幅提升理解和记忆能力，但响应会变慢。 |
| **最大语音缓存数量** | 最多保留的临时语音文件数，超过会自动清理最旧的。 |

### GPT-SoVITS 模型与推理参数

| 配置项 | 说明 |
| :--- | :--- |
| **模型文件夹所在路径** | **必填** ，填写你的 ckpt 和 pth 文件夹路径  |
| **超时时间** | TTS 请求的超时时间，默认 `120` 秒。 |
| **默认参考音频文本** | 仅当情绪文件夹内没有 `asr.txt` 时作为兜底使用。 |
| **参考音频文本语言 / 文本语言** | 默认为 `ja`（日语），可改为 `zh`（中文）`en`（英文）等。 |
| **核采样的阈值 (top_k) / (top_p)** | 数值越大语气变化越丰富，常用于提高情感表现力。 |
| **生成语音的随机性 (temperature)** | 越高语气起伏越大，常用于提高情绪爆发力。 |
| **切分文本的方法** | `cut0` 到 `cut5`，默认 `cut1`（四句一切）。 |
| **批处理大小 / 阈值 / 分桶** | 并行处理相关设置，默认即可。 |
| **语音播放速度** | 1 为原始语速，可微调。 |
| **流模式 / 随机种子 / 并行推理** | 建议保持默认（关闭流模式，开启并行推理）。 |
| **重复惩罚因子** | 数值越大越不容易重复字词，默认 `1.35`。 |
| **输出媒体的类型** | 建议保持 `wav` 以获得最优音质。 |
