## ✨ 功能特性

- **全自动情绪路由**：根据大模型判断的语境，自动在 平静、高兴、害羞、生气、惊讶、着急 等情绪之间切换语气。
- **双回复模式**：大模型同时生成中文台词和自选台词，QQ 中先发送自选语音，紧接着发送自选文本。
- **外部目录自动扫描**：插件强制要求在插件UI中配置外部参考音频根目录，自动扫描根目录下的子文件夹作为情绪库。
- **参考文本自动加载**：自动读取对应文件夹下的 `asr.txt` 作为 TTS 参考文本，无需手动粘贴。
- **严格 JSON 输出**：内置细致的人格提示词，强制大模型输出例如 `{"zh": "中文台词", "ja": "日语台词", "emotion": "情绪"}` 格式，防止模型乱回。
- **GPT-SoVITS 全参数可调**：整合了详细推理参数（Top-K、Temperature、切分方法、批处理等），用户可在插件UI中自由调节语音质量、随机性和语速。
- **深度思考（Think）**：开启后模型会先进行内部推理，大幅度提升对复杂指令和长对话的理解能力，解决小模型“失忆”和“敷衍”的问题。
- **多角色支持**：可配置多个角色（不同人设、提示词、语气库、语言），通过插件UI或WebUI一键切换，记忆文件按角色独立保存。
- **情绪强度自动调节**：LLM 可为每句话评估 0~1 的强度值，自动调整语音合成的随机性和音色丰富度，让情感表达更细腻真实。
- **现实时间感知**：开启后 LLM 可获知当前时间（服务器本地时间），使对话更自然（如早上好、晚上好等）。
- **对话上下文自动摘要**：当历史消息超过阈值时，自动调用 LLM 对旧对话进行摘要，压缩 token 使用，防止模型遗忘或降智。
- **图片识别回复**：支持配置多模态模型，对用户发送的图片进行理解并生成带情绪的语音回复（需部署视觉模型）。
- **记忆管理 WebUI**：提供独立 Web 界面，可搜索、查看、删除记忆文件，批量导出聊天记录，备份/恢复配置与记忆。
- **按角色管理记忆**：记忆文件按“角色标识符”独立保存在全局目录中，卸载或重装插件也不会丢失记忆，且支持在UI中扫描、删除指定角色的记忆文件。
- **语音缓存自动清理**：自动限制临时音频文件的数量，防止长时间使用后磁盘被占满。
- **高级发送控制**：支持语音分开发送、文本分开发送、动态等待、仅私聊响应等模式，适配不同平台限制。


## 📦 环境要求

- 已部署并运行的 **AstrBot** 实例（v4.x 版本）。
- 本地 **Ollama** 或 **OpenAI 兼容服务**（配置好对话模型，如 `qwen3:8b`）。
- 本地 **GPT-SoVITS** 服务（运行于 `http://127.0.0.1:9880`）。
- **重要**：参考音频必须存放在 **外部可访问的常规目录**（如 `C:/tts/yuqi/`），严禁放入 `%APPDATA%` 等隐藏系统目录。
- 如需图片识别功能，需额外部署多模态视觉模型（如 `llava`、`qwen-vl` 等）。


## 🧠 配置本地大语言模型（LLM）后端

本插件支持 **Ollama** 以及所有 **OpenAI 兼容接口** 的本地部署软件（如 LM Studio、vLLM、LocalAI 等）。请在插件配置面板中，根据你使用的软件填写以下三项：

### 📋 配置参数对照表

| 软件 | 【LLM后端类型】 | 【LLM服务地址】 | 【大语言模型名称】 | 【本地模型API Key】 |
| :--- | :--- | :--- | :--- | :--- |
| **Ollama** | `ollama` | `http://127.0.0.1:11434` | `自定义` | 留空 |
| **LM Studio** | `openai` | `http://127.0.0.1:1234/v1` | `自定义` | 任意字符串（如 `lm-studio`） |
| **vLLM** | `openai` | `http://127.0.0.1:8000/v1` | `自定义` | `EMPTY` |
| **LocalAI** | `openai` | `http://127.0.0.1:8080/v1` | `你的 gguf 模型名` | `EMPTY` |

### 🛠️ 配置步骤

1. 在插件 插件 UI 面板中找到 **【LLM后端类型】**。
2. 根据你使用的软件，选择 `ollama` 或 `openai`。
3. 填写 **【LLM服务地址】**（注意：OpenAI 兼容接口通常需要在末尾加 `/v1`）。
4. 填写 **【大语言模型名称】**（必须与你本地部署的模型名称完全一致）。
5. 填写 **【本地模型API Key】**（Ollama 留空，OpenAI 兼容接口一般填任意字符串或 `EMPTY`）。


## 🖼️ 配置图片识别（可选）

如需让角色对图片进行语音回复，需额外配置多模态模型：

1. 在插件UI中找到 **【识图模型名称】**，填写一个支持视觉的模型名称（如 `llava:7b`、`qwen2.5-vl:7b` 等）。
2. 选择 **【图片回复模式】**：
   - `plugin`：强制使用插件识图模型（需已填写模型名称）。
   - `official`：交给 AstrBot 官方 LLM 处理（需在 AstrBot 配置文件中正确配置视觉模型）。
   - `auto`：配置了识图模型就用，否则交给官方。
3. 调整 **【识图模型请求超时时间】**（默认90秒）。

注意：识图模型需支持多模态输入，否则会报错。若未配置，图片消息将不会触发插件回复。


## ⚠️ 注意事项

- 如果你使用的是 **OpenAI 兼容后端**，但模型返回的内容不是严格的 JSON 格式（例如纯文本），请检查【JSON提示词】是否足够强硬。
- 对于 **LM Studio**，请确保已在软件中启动本地 API 服务，并允许跨域访问。
- 修改配置后，请务必在 插件 UI 中点击 **保存并重载插件** 使新配置生效。
- **图片识别** 和 **对话摘要** 功能会额外调用 LLM，请确保模型支持且响应速度可接受。
- 多角色模式下，每个角色可拥有独立的语气文件夹和提示词，但请确保参考音频根目录配置正确。


## 🎁 如何自定义新语气？（适配大众）

1. 在上述根目录下新建一个拼音文件夹（例如你想加“傲娇”，就建一个名为 `aojiao` 的文件夹）。
2. 将音频文件命名为 `ref.mp3`（或 `ref.wav`）放入该文件夹。
3. 在 插件 UI 中无需额外配置，重载插件后代码会自动扫描出新情绪并加入大模型的情绪列表中。
4. 若需要为不同角色设置独立语气库，可在多角色配置中指定每个角色的 `ref_audio_root`。


## 🖥️ WebUI 使用指南

插件启动后，可通过 AstrBot 的插件页面访问 WebUI，进行以下操作：

### 1. 记忆文件管理
- **列表视图**：显示所有角色的记忆文件，包含角色名、会话对象、最后一句对话。
- **搜索**：输入关键字按文件名、显示名称或内容搜索。
- **角色过滤**：按角色筛选记忆文件。
- **排序**：支持按角色分组（组内最新）、最新对话、最旧对话排序。
- **多选操作**：点击“多选”后可批量选择文件，进行批量删除或导出。
- **查看聊天记录**：双击文件或选中后点击“查看聊天记录”进入对话详情页。
- **删除消息**：在聊天记录页可开启多选，删除单条或多条消息。

### 2. 导出/恢复
- **导出选中**：将选中的记忆文件导出为 JSON 格式，浏览器自动下载。
- **导出当前聊天记录**：在聊天记录视图可导出当前文件为 JSON。
- **备份**：在插件后端 API 中支持全量备份（配置+记忆），前端暂未提供按钮，可通过浏览器直接访问 API 或使用“恢复”功能导入备份文件。
- **恢复**：点击“恢复”按钮上传之前导出的 JSON 文件（支持导出格式和完整备份格式），恢复时采用合并模式，不会删除现有文件。

### 3. 角色切换
- 可通过插件设置中的 `active_character` 切换。
- 切换后，新消息将使用新角色的人设、语气库和记忆文件（记忆按角色隔离）。


## 🚀 速度优化建议

- **精简提示词**：如果觉得仍慢，可以手动精简提示词，去除冗余描述。
- **开启深度思考**：如果需要模型准确理解复杂的上下文指令，或AI太傻没不懂潜在意思，建议开启【深度思考】，但会牺牲一定响应速度。
- **删去人格提示词中的第二段JSON**：让AI一次只回复一种语气。**通常不建议**，因为会导致在同一句话中语气应有明显不同时，只会有第一种语气。
- **关闭对话摘要**：如果模型速度极慢且不经常长对话，可关闭 `summary_enabled` 以节省额外 LLM 调用。
- **降低图片识别频率**：图片识别较慢，可在不需要时留空 `image_caption_model_name` 或选择 `official` 模式。


## ❓ 常见问题

- **没有声音/合成失败 (400 Bad Request)**：请检查“参考音频根目录”是否填写了外部常规目录（如 `C:/tts/yuqi/`），严禁填写 `C:/Users/AppData/.astrbot/...` 这种隐藏系统目录。
- **语气没有变化**：请确保开启了 `llm_judge`，并且 `ref.mp3` 本身情绪饱满（不要用太平的音）。
- **模型不听话（不输出 JSON）**：请检查 **人格提示词** 中是否包含了强制输出 `{"zh": "...", "ja": "...", "emotion": "..."}` 格式的约束语句（插件已内置）。
- **后台日志显示乱码**：插件已内置强制 UTF-8 输出修复。若依然显示乱码，请务必检查文件夹是否使用了中文命名，统一改为拼音即可。
- **怎么运行本地 GPT-SoVITS 服务**：在文档上方有GPT-SoVITS 服务的链接，请没有下载的人群前往下载。丛雨模型请查看此md文档最上方有github链接供安装。
- **图片识别无反应**：请确认已正确填写 `image_caption_model_name` 且模型支持图像输入，并检查 `image_reply_mode` 设置。
- **多角色切换后没有变化**：请确保 `active_character` 配置正确，且该角色在 `roles` 列表中有定义；切换后可能需要重启插件才能完全生效（但大部分运行时会即时更新）。
- **WebUI 导出文件无法下载**：由于 AstrBot 沙箱限制，请右键 WebUI 页面复制链接到浏览器中操作导出。

| **允许 LLM 自动判断情绪强度** | 开启后 AI 为每句话评估强度值，自动调整语音参数。 |

| 配置项 | 说明 |
| :--- | :--- |

| **生成语音的随机性 (temperature)** | 越高语气起伏越大。 |
| **切分文本的方法** | `cut0` 到 `cut5`，默认 `cut1`（四句一切）。 |
| **批处理大小 / 阈值 / 分桶** | 并行处理相关设置。 |
| **语音播放速度** | 1 为原始语速。 |
| **流模式 / 随机种子 / 并行推理** | 建议保持默认。 |
| **重复惩罚因子** | 数值越大越不容易重复字词。 |
| **输出媒体的类型** | 建议保持 `wav`。 |
| **语气渐变** | 开启后不同情绪句子间平滑过渡。 |
| **呼吸间隙（毫秒）** | 前一句说完后的停顿时间。 |
| **交叉渐变长度（毫秒）** | 两句话重叠过渡的时长。 |
| **情绪强度对语音变化幅度的影响** | 强度影响随机性。 |
| **情绪强度对语音音色丰富度的影响** | 强度影响 top_k。 |

## 🗂️ 核心外部文件夹结构（自动扫描）

由于插件的 TTS 服务无法访问插件内部的隐藏目录，你必须将音频文件放在插件UI填写的“参考音频根目录”下。**强烈建议使用拼音以避免 Windows 乱码问题。**

```text
以下是例子：
D:/tts/yuqi/
├── pingjing/           (平静情绪文件夹)
```
