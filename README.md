# 本地TTS语气变化

基于 AstrBot 的全自动情绪 TTS 插件。支持通过本地大模型自动判断语境情绪，联动本地 GPT-SoVITS 生成带情绪起伏的日语语音，并实现**中文文本 + 自选语言语音双回复**，直接发送至 QQ。
为什么做这个，插件市场不是已经有类似的吗：因为我不会使用()，而且添加起来太麻烦，于是我想到用 https://github.com/kuxiaowo/AIpet-Murasame 这个AIpet中的来根据模型生成的语句，让模型再自己判断使用文件夹中的什么语气，最后合成出语气不同的语音并发送至QQ。

## ✨ 功能特性

- **全自动情绪路由**：根据大模型判断的语境，自动在 `平静`、`高兴`、`害羞`、`生气`、`惊讶`、`着急` 等情绪之间切换语气。
- **双回复模式**：大模型同时生成中文台词和日语台词，QQ 中先发送日语语音，紧接着发送中文文本。
- **外部目录自动扫描**：插件强制要求在 WebUI 中配置外部参考音频根目录，自动扫描根目录下的子文件夹作为情绪库。
- **参考文本自动加载**：自动读取对应文件夹下的 `asr.txt` 作为 TTS 参考文本，无需手动粘贴。
- **严格 JSON 输出**：内置细致的人格提示词，强制大模型输出 `{"zh": "中文台词", "ja": "日语台词", "emotion": "情绪"}` 格式，防止模型乱回。
- **GPT-SoVITS 全参数可调**：整合了详细推理参数（Top-K、Temperature、切分方法、批处理等），用户可在 WebUI 中自由调节语音质量、随机性和语速。

## 📦 环境要求

- 已部署并运行的 **AstrBot** 实例（v4.x 版本）。
- 本地 **Ollama** 服务（配置好对话模型，如 `qwen3.5:4b`）。
- 本地 **GPT-SoVITS** 服务（运行于 `http://127.0.0.1:9880`）。
- **重要**：参考音频必须存放在 **外部可访问的常规目录**（如 `C:/AIpet/...`），严禁放入 `%APPDATA%` 等隐藏系统目录。

## 🎁 如何自定义新语气？（适配大众）

1. 在上述根目录下新建一个拼音文件夹（例如你想加“傲娇”，就建一个名为 `aojiao` 的文件夹）。
2. 将音频文件命名为 `ref.mp3`（或 `ref.wav`）放入该文件夹。
3. 在该文件夹下新建一个 `asr.txt`，在 txt 中写入该音频对应的文字（必须完全一致）。
4. 重载插件。代码会自动扫描出 `aojiao`，并将其加入大模型的情绪列表中。

## 🚀 速度优化建议

- **不要填写模型权重路径**：这非常重要！在插件 WebUI 中，请之前在“模型提供商→文字转语音”中**没有设置过模型路径的**务必保持“GPT/SoVITS模型文件路径”为空，避免 TTS 每次请求都重新加载模型。
- **精简人格提示词**：如果觉得仍慢，可以手动精简 `persona_prompt`，去除冗余描述。

## ❓ 常见问题

- **没有声音/合成失败 (400 Bad Request)**：请检查“参考音频根目录”是否填写了外部常规目录（如 `C:/tts/...`），严禁填写 `C:/Users/.../.astrbot/...` 这种隐藏系统目录或只填写盘符。
- **语气没有变化**：请确保开启了 `llm_judge`，并且 `ref.mp3` 本身情绪饱满（不要用太平的音）。
- **模型不听话（不输出 JSON）**：请检查 **人格提示词** 中是否包含了强制输出 `{"zh": "...", "ja": "...", "emotion": "..."}` 格式的约束语句（插件已内置）。
- **后台日志显示乱码**：插件已内置强制 UTF-8 输出修复。若依然显示乱码，请务必检查文件夹是否使用了中文命名，统一改为拼音即可。
- **怎么运行本地 GPT-SoVITS 服务**：在 `https://github.com/RVC-Boss/GPT-SoVITS` 中点击 Releases 选择所需要的版本下载。丛雨模型请在 WebUI 中选择“参考音频根目录”和“语音包下载及解压的根路径”后开启“点击开始一键下载和解压”并点击保存并关闭。
- **运行本地 GPT-SoVITS 服务 bat**：用记事本或 VScode 修改下载的 `yuqi` 文件夹中（路径在平台日志查看）的 bat 批处理文件的路径，修改为自己下载 GPT-SoVITS 时选择的路径。

## ⚙️ 配置说明（WebUI 中必须填写）

### 核心路由配置

| 配置项 | 说明 |
| :--- | :--- |
| **是否使用 LLM 自动判别情绪** | 开启后，大模型会根据语境自动选择情绪。关闭则固定使用默认情绪。 |
| **GPT-SoVITS 服务地址** | 填写本地 API 地址，默认为 `http://127.0.0.1:9880`。 |
| **参考音频根目录** | **【必填】** 填写外部绝对路径，例如：`C:/tts/yuqi`。 |
| **默认情绪** | 当大模型无法识别情绪时使用的兜底情绪（必须与文件夹名一致，默认 `pingjing`）。 |
| **人格提示词** | 内置了完整的丛雨人格设定及 JSON 输出要求，可自行修改。 |
| **情绪映射配置** | **【可选】** 留空（保持暂无条目）即可自动扫描外部目录。 |

### GPT-SoVITS 模型与推理参数

| 配置项 | 说明 |
| :--- | :--- |
| **GPT/SoVITS模型文件路径** | **强烈建议留空！** 请之前在“模型提供商→文字转语音”中没有设置过模型路径的务必保持“GPT/SoVITS模型文件路径”为空。若填写绝对路径，会导致每次语音合成时重复加载模型，极其卡顿。请让后台的 TTS 服务直接使用默认加载好的模型。 |
| **超时时间** | TTS 请求的超时时间，默认 `120` 秒。 |
| **默认参考音频文本** | 仅当情绪文件夹内没有 `asr.txt` 时作为兜底使用。 |
| **参考音频文本语言 / 文本语言** | 默认为 `ja`（日语），可改为 `zh`（中文）。 |
| **核采样的阈值 (top_k) / (top_p)** | 数值越大语气变化越丰富，常用于提高情感表现力。 |
| **生成语音的随机性 (temperature)** | 越高语气起伏越大，常用于提高情绪爆发力。 |
| **切分文本的方法** | `cut0` 到 `cut5`，默认 `cut5`（按标点符号切）。 |
| **批处理大小 / 阈值 / 分桶** | 并行处理相关设置，默认即可。 |
| **语音播放速度** | 1 为原始语速，可微调。 |
| **流模式 / 随机种子 / 并行推理** | 建议保持默认（关闭流模式，开启并行推理）。 |
| **重复惩罚因子** | 数值越大越不容易重复字词，默认 `1.35`。 |
| **输出媒体的类型** | 建议保持 `wav` 以获得最优音质。 |

## 🗂️ 核心外部文件夹结构（自动扫描）

由于插件的 TTS 服务无法访问插件内部的隐藏目录，你必须将音频文件放在 WebUI 填写的“参考音频根目录”下。**强烈建议使用拼音以避免 Windows 乱码问题。**

```text
D:/tts/yuqi/
├── pingjing/           (默认情绪文件夹)
│   ├── ref.wav         (参考音频)
│   └── asr.txt         (音频对应的文本)
├── gaoxing/
│   ├── ref.mp3
│   └── asr.txt
├── haixiu/
│   ├── ref.mp3
│   └── asr.txt
├── shengqi/
│   ├── ref.mp3
│   └── asr.txt
├── jingya/
│   ├── ref.mp3
│   └── asr.txt
└── zhaoji/
    ├── ref.mp3
    └── asr.txt
```
